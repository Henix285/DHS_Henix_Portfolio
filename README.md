# DHS Henix Portfolio

## Run the portfolio

Install workspace dependencies with `pnpm install`, then start the frontend with:

```sh
pnpm dev
```

The portfolio is served by Vite at `http://localhost:5173`.

## Project layout

- `frontend/portfolio` — the public portfolio website
- `frontend/mockup-sandbox` — the component mockup preview app
- `backend/api-server` — the API service
- `lib/` — shared API and database packages
- `attached_assets/` — original media and source assets
- `scripts/` — workspace scripts
